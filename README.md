# 社群足跡心智圖 2025–2026

> **🔗 線上瀏覽：[https://tonnychiulab.github.io/social-mindmap/](https://tonnychiulab.github.io/social-mindmap/)**

以互動式心智圖呈現一整年的個人社群媒體使用行為，資料來源為 Facebook 個人資料匯出包，所有內容均已完整去識別化。涵蓋發文習慣、主題詞彙、媒體資產、打卡地點等六大分析維度。

## 心智圖六大分支

- **活動統計**：發文頻率、高峰時段、月份趨勢
- **主題詞彙**：高頻詞分析、內容主題分類（AI 科技、資安宣導、攝影、生活）
- **媒體檔案**：照片與影片資產統計、貼文類型佔比
- **發文時間軸**：24 小時時段分佈、季節性活躍度波動
- **打卡地點**：廟宇信仰、登山步道、餐廳美食、跨縣市足跡
- **數位記錄**：個人數位行為綜合側寫
